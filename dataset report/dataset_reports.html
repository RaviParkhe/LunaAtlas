Processing Pipeline
  1. Ingest LOLA RDR altimetric point returns; geolocate using LRO orbit/pointing solutions.
  2. Iteratively co-adjust tracks in 64 overlapping 80 km tiles to remove orbital geolocation artifacts; reject noise via slope/run-length criteria.
  3. Grid cleaned, adjusted tracks to 20 m/pixel using natural-neighbor interpolation.
  4. Downsample by multi-pixel averaging to 80 m/pixel and package as a georeferenced Cloud-Optimized GeoTIFF.
Validation Check
  • CRS and resolution confirmed against official PGDA product page (south polar stereographic, 80 m/pixel).
  • Elevation value / no-data validation — not checked, requires the raw GeoTIFF.
Known Limitations
  • LOLA track density near the pole is uneven; interpolated pixels carry higher uncertainty than directly sampled ones.
  • This 80 m product is downsampled from the native 20 m grid, not gridded directly from raw tracks at 80 m.

Processing Pipeline
  1. Search WAC (70–100 m/px), TC (30 m/px), and LOLA/LOLA+TC hillshade DTMs (5–60 m/px) multiple times each.
  2. Manually trace crater rims where visible, at ~2.5 pixels per vertex point.
  3. Fit circles/ellipses to rim points using Great Circle distances and bearings.
  4. Compile ~1.3M fitted craters into a PDS4-archived CSV with unique identifiers.
Validation Check
  • Completeness cross-checked via crater size-frequency statistics and comparison with other published databases (per source paper).
  • Field-level value validation — not checked, requires the raw CSV.
Known Limitations
  • Complete only for craters ≳1–2 km; completeness varies by terrain (better in flat maria than rugged highlands).
  • No independent smaller-crater database exists to produce a true completeness report; individual crater accuracy is "best effort."

Processing Pipeline
  1. Use LOLA-derived polar DEM as topographic basis for horizon computation.
  2. Model solar position and local horizon across multiple lunar precession cycles (Mazarico et al. 2011 method).
  3. Average per-pixel sunlit fraction over the modeled period (0–100%).
  4. Package as PDS3 binary IMG with this detached ASCII label describing structure/projection.
Validation Check
  • Resolution and coverage confirmed against the official LOLA illumination products index.
  • Publisher errata on record: an earlier release of this exact label had incorrect LINE/SAMPLE values, later corrected.
Known Limitations
  • Label text could not be parsed directly in this session (server returned binary content); fields sourced from related publisher documentation.
  • Illumination values are a multi-year model average, not an instantaneous measurement — short-term shadowing is not captured.
